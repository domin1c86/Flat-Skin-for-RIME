# 扁平灰白

灰白扁平键帽、蓝色回车，浅色深色及 iPhone 横竖屏。

## 安装与方案

将「扁平灰白.cskin」分享给元书，重新导入并启用。先确认 double_pinyin_flypy 和 melt_eng 已安装并加入方案列表。

中英按钮同时切换布局与方案：中文→独立英文键盘＋Easy English Nano；英文→中文键盘＋小鹤双拼－薄荷定制。返回中文固定使用小鹤双拼，不自动记忆其他中文方案。

工具栏从左到右是菜单、留白、符号、Emoji、剪贴板、方案选择。方案选择打开皮肤自己的面板：小鹤双拼－薄荷定制、薄荷全拼、薄荷小鹤混输、Easy English Nano。每项同时选择键盘与方案；面板不扫描已安装方案，所选方案需事先安装启用。取消选择可返回原键盘。

英文词库候选需要 melt_eng 的 ASCII-OFF 状态；请在元书确认手机上方案配置与候选。皮肤不修改薄荷方案文件，不强制英文自动句首大写，也不设置原生长按时间。

通过元书应用或原生菜单单独更换方案／ASCII 状态时，不保证同步改变布局；使用本皮肤中英按钮或方案面板重新同步。冷启动恢复是否匹配需实机确认。

## 主界面与符号

三行 QWERTY；底行为符号、123、逗号、空格、句号、中英、回车。

中文键面与普通字母气泡为大写，点按发送拼音字母；英文键面与普通气泡跟随 Shift。上标、上滑气泡、上滑动作、长按符号项在每份布局中一致，不依赖语言通知。数字均保持半角；中文使用全角符号和弯引号，英文使用半角，H/J 均为直双引号。例如 F 中文为 ＃、英文为 #。

上滑和长按符号均直接上屏，不经过 RIME 转换。长按保留大写／符号／小写三项，默认选择符号；靠左、靠右的排序与锚点镜像适配。22.5pt 字号、8.5pt 圆角、无描边、柔和阴影，支持旧版单行回退。原生触发时间与手势互斥由元书处理，须实机检查。

中／英图标与中文逗号句号居中效果沿用已确认设计。iPhone 拼音预编辑 12pt、候选 16pt；音节分隔由输入方案控制。空格在预编辑时保持候选选定行为。

数字页左侧运算符、中间九宫格、右侧删除／句点／@，底部返回使用 returnPrimaryKeyboard。符号页常用／中文／英文分类保持圆角内缩高亮，锁定可连续输入，返回使用 returnLastKeyboard；请验证英文状态下返回正确主键盘。

Emoji 保留原生页，未保证默认进入笑脸分类；打开后可手动点笑脸分类。数字页、符号页、iPad 的原有工具栏保留。

iPad 普通布局与分体保持原有行为；浮动键盘复用 iPhone 布局。独立英文符号功能本轮以 iPhone 和浮动键盘为目标。
