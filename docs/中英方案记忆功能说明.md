# 中英方案记忆功能

> 最新版本同时记忆英文词库候选开关。英文逗号长按开关与安装更新说明见 [英文词库候选开关修改报告](英文词库候选开关修改报告.md)。

现在中英按钮在“最近一次中文方案”和 Easy English Nano 之间切换：

| 最近选择的中文方案 | 点击中英按钮的往返对象 |
| --- | --- |
| 薄荷全拼 `rime_mint` | 薄荷全拼 ↔ Easy English Nano |
| 小鹤双拼 `double_pinyin_flypy` | 小鹤双拼 ↔ Easy English Nano |
| 小鹤混输 `rime_mint_flypy` | 小鹤混输 ↔ Easy English Nano |

选择新的中文方案会更新记忆，直接选择英文不会覆盖它。无记录或记录不属于上述中文方案时，回退到小鹤双拼。字母、标点、工具栏、长按气泡和候选字号设计保持原样。

## 必须同时更新皮肤与输入方案文件

1. 重新导入并启用最新 `dist/扁平灰白.cskin`。
2. 解压 `dist/元书皮肤配套补丁.zip`，将四份 `.custom.yaml` 放在当前薄荷方案目录的 schema 文件旁边，将 `skin_scheme_memory.lua` 放在同目录下的 `lua/` 文件夹。
3. 文件管理路径：应用文件 → RimeUserData → 实际使用的薄荷方案目录。手机有其他自定义条目时合并四份补丁中的 `patch:`，不要覆盖原配置或重复声明 `patch:`。
4. 在元书重新部署。首次使用通过皮肤方案面板选一次你要用的中文方案，再点中英按钮往返检查。

四份补丁是 `double_pinyin_flypy.custom.yaml`、`rime_mint.custom.yaml`、`rime_mint_flypy.custom.yaml`、`melt_eng.custom.yaml`。相较上一轮，每份新增：

```yaml
patch:
  "engine/processors/@before 0": lua_processor@*skin_scheme_memory
```

这条是新增项目，其他条目保持上一轮设置。它让处理器先于原有按键处理器接收专用组合键；不替换原有处理器列表。Lua 文件必须一并安装，不能只加入这条补丁。

Lua 源码保存在项目 `scripts/rime/skin_scheme_memory.lua`，已将同内容复制到你的 `external_files/oh-my-rime/lua/`。用户备份目录的忽略规则保留，本次不会将个人词库与数据库整包加入 Git。

只导入皮肤没有安装处理器时，记忆切换不会生效；此时仍可用皮肤方案面板直接选择方案。补丁 ZIP 是配套文件，不能替换整个薄荷目录，也不是皮肤包。

## 记忆如何保存

皮肤中英按钮切换对应布局，并发送 `Control+Shift+F12`。配套 Lua 处理器在 RIME 中决定目标方案，确认当前预编辑后切换，中文保持 ASCII 直通关闭，英文恢复保存的词库候选开关。

Lua 在当前 RIME 用户目录生成 `skin_scheme_memory.yaml`：

```yaml
last_chinese_schema: rime_mint
english_candidates_enabled: true
```

保存一个中文方案 ID 与一个英文候选布尔开关，不保存输入文字，不编辑 `user.yaml`、个人词频数据库或 schema 源文件。重复选择相同方案不重复写入。横竖屏、深浅色和数字／符号页不修改此记录。

记录可跨引擎进程读取；能否在元书键盘的实际文件权限、会话恢复与同步环境中正常写入，仍需实机确认。如果写入失败，当前 Lua 运行会话内仍有记忆，不能保证重启后恢复。删除记录后需重启键盘／相关宿主会话才能清除运行时缓存；没有记录时回退小鹤双拼。

网页使用浏览器本地存储演示记忆，可刷新保留；它不读写手机的记录文件。显式 URL 的中文 schema 参数会作为本次选定方案，无 schema 参数时恢复本地记忆。

其他输入方案不会成为记忆对象。通过元书原生菜单改方案，Lua 可在支持方案加载时记录中文 ID，但该菜单仍不保证同步皮肤布局；建议使用皮肤方案面板。专用组合键还可由外接键盘触发 RIME 方案切换，但不会替外接键盘切换皮肤布局。

- 元书 1.11.0(558)、RIME 1.17.0 的 iPhone 实机结果仍待验证；Windows 引擎和网页结果不能替代它。

## 实机重点

先选择全拼，点两次中英按钮确认回到全拼；再分别选择小鹤双拼、小鹤混输重复检查。切到英文后退出／重新打开键盘，再验证返回方案。存在中文或英文预编辑时也要检查切换前的候选是否正确提交一次，避免丢字或重复上屏。

本功能没有调整原生长按时间、自动句首大写、下一词预测、Emoji 默认分类或音节分隔，沿用上一轮报告中的元书侧设置说明。
