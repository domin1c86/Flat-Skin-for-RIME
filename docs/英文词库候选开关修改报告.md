# 英文逗号长按开关与记忆

日期：2026-10-10（UTC+8）。本次修改已与上一轮中英方案记忆合并。

## 怎样使用

英文主键盘点按 `,` 仍输入逗号。长按出现单项气泡「切换词库候选」，松手切换一次：

| 逗号上方标识 | 输入状态 | 实际行为 |
| --- | --- | --- |
| 蓝色「词」 | 候选开启，ASCII-OFF | 普通字母进入 Easy English Nano，可选择单词候选及补全 |
| 灰色「词」 | 候选关闭，ASCII-ON | 普通字母直接上屏，不查询词库候选 |

长按不输入逗号；移动远离候选、触摸取消、切页或关闭预览会取消。按住期间只显示气泡，松手才执行，不使用连续触发的 `repeatAction`。气泡单元格 88×44pt、字号 12pt；沿用现有 8.5pt 圆角和阴影。「词」为 9pt，逗号字号与位置保持原样。

关闭时，未提交的原始英文编码先直接上屏，保留大小写，不自动选择补全词：`hel` → `hel`、`Hel` → `Hel`。再次开启只影响后续输入，不修改已经上屏的文字。

这是单词候选开关，不新增下一词预测，也不是仅隐藏候选栏。

## 记忆与兼容

原来的 `skin_scheme_memory.yaml` 增加一个布尔值：

```yaml
last_chinese_schema: rime_mint
english_candidates_enabled: false
```

旧记录没有开关字段，或字段无法解析为布尔值时，默认开启；明确的 `false` 不会被当成缺失。保存候选开关时保留中文方案，选择新的中文方案时保留候选开关。不记录输入文字，不改写个人词频数据库。

切回中文仍使用最近中文方案，并关闭中文 ASCII 直通。通过中英按钮、方案面板再次进入英文，以及启动新引擎进程时，恢复保存的英文开关。写入失败时，当前 Lua 会话内仍能记忆，重启恢复需要手机文件权限支持并实测。

长按保存的是你选择的开关；原生菜单临时改变 ASCII 状态不会替代这个记录。「词」标识显示当前实际 ASCII 状态，再长按会按当前状态切换并保存。

## 修改内容

- 只改变四份英文主键盘配置中的逗号相关节点；其他 24 份配置与本次修改前一致。iPhone 横竖屏、深浅色和复用配置的浮动键盘支持；普通 iPad、中文、数字、符号界面保持原样。
- 英文逗号使用单项长按网格，并提供单行列表回退。动作是 `sendKeys: Control+Shift+F11`，仅由 `melt_eng` 中的配套 Lua 响应；中英切换 F12 保持原有用途。
- 逗号首次加载使用完整条件前景，ASCII 变化通知保留背景、尺寸、点按／上滑动作和两种长按引用，避免空白或失去功能。
- Lua 记录结构由单个中文 ID 扩展为中文 ID 加候选开关，恢复英文时按记录设置 `ascii_mode`。英文补丁的 `switches/@0/reset` 改为 `-1`，避免引擎初始化最后阶段再次固定重置成候选开启。
- 更新离线 HTML、配置示意图、README、实机清单和配套 ZIP。网页使用独立本地存储，只演示交互，不运行 RIME 或模拟真实词库。

## 更新方法

1. 导入并启用最新 `dist/扁平灰白.cskin`。
2. 解压最新 `dist/元书皮肤配套补丁.zip`：四份 `.custom.yaml` 放在元书当前薄荷方案目录的 schema 文件旁，`skin_scheme_memory.lua` 放在该目录的 `lua/` 下。
3. 手机存在额外同名自定义配置时，合并到唯一的 `patch:`，不要覆盖其他条目。特别确认英文补丁为 `"switches/@0/reset": -1`，不要沿用旧说明中的固定 `0`。
4. 在元书重新部署，再从皮肤入口选择英文验证。仅导入皮肤不安装 Lua，长按开关不能生效。

无需删除已有的记忆文件；旧文件会兼容读取。补丁 ZIP 不是完整词库包，不要替换整个薄荷目录。

Lua 的项目源码位于 `scripts/rime/skin_scheme_memory.lua`，相同版本已复制到你的 `external_files/oh-my-rime/lua/`。用户原始 schema、词库与数据库保留；你的 `.gitignore` 改动不纳入本次提交。
