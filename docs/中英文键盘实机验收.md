# 独立中英文键盘实机验收

状态：待用户在元书 1.11.0(558) 上执行。配置与 HTML 检查不替代以下结果。

## 准备

- [ ] 保留旧皮肤作为回退，重新导入并启用本轮「扁平灰白.cskin」。
- [ ] 四个方案均已安装并启用；更新四份配套补丁和 `lua/skin_scheme_memory.lua` 并重新部署，确认英文方案 ASCII-OFF 可以产生词库候选。
- [ ] 从皮肤中英按钮切英文，看到英文小写键面；回中文后为大写键面。

## 第一阶段：最小验收

以下按键均分别做上滑与长按默认项输入；复制实际结果核对码点，不只凭外观判断。

| 按键 | 中文结果 | 英文结果 |
| --- | --- | --- |
| Q | 1 U+0031 | 1 U+0031 |
| F | ＃ U+FF03 | # U+0023 |
| H | “ U+201C | ' U+0027 |
| J | ” U+201D | & U+0026 |
| A | ～ U+FF5E | ~ U+007E |
| L | ？ U+FF1F | ? U+003F |
| C | - U+002D | - U+002D |
| V | _ U+005F | _ U+005F |
| M | 反引号 U+0060 | / U+002F |
| 底行逗号 | ， U+FF0C | , U+002C |
| 底行句号 | 。 U+3002 | . U+002E |

- [ ] 中文冷启动，首次输入即可达到上表结果。
- [ ] 英文状态离开键盘、重新打开；再重启宿主 App 检查恢复的布局与输入方案一致。
- [ ] 中→英→中与反向切换，每次同时改变布局和方案；A/L 居中、气泡锚点稳定。
- [ ] 普通/Shift/大写锁定：英文普通气泡为当前字母大小写，符号不受影响。
- [ ] 有/无预编辑文字时输入符号：不误转换、不重复输入、候选处理符合预期。
- [ ] 英文普通字母生成实际单词候选，可选中并上屏；网页无法验证此项。
- [ ] 英文→数字→返回仍为英文；英文→符号→返回仍为英文；数字→符号→返回为数字。
- [ ] 方案面板选择四项，分别加载对应方案与主键盘；取消不更换方案。
- [ ] 中／英文主界面最右侧向下箭头可收起键盘；重新点击输入框可恢复。浅／深色及横／竖屏均不遮挡方案按钮。
- [ ] 有预编辑或下一词联想时收起：不误选联想词、不重复提交；重新打开后可正常继续输入。

## 中文方案记忆验收

- [ ] 选择全拼，连续进行全拼→英文→全拼，仍为 rime_mint。
- [ ] 选择小鹤双拼、小鹤混输后分别往返，返回各自方案。
- [ ] 直接选择英文、数字／符号返回、横竖屏变化不覆盖中文记忆。
- [ ] 切到英文后离开键盘／重启宿主 App，再点中英按钮返回正确的中文方案。
- [ ] 当前用户目录中 skin_scheme_memory.yaml 记录正确方案；存在预编辑时切换不丢字或重复提交。

## 英文候选开关验收

- [ ] 逗号短按只输入逗号；长按气泡松手只切换一次，持续按住、取消与切页不误输入。
- [ ] 「词」蓝色时有英文候选；灰色时普通字母直接上屏，Shift 大小写正确。
- [ ] 输入 `hel`／`Hel` 后关闭，只提交原字母一次，不提交补全词。
- [ ] 关闭后中英往返、方案面板进入英文、重启宿主会话仍保持关闭；中文仍有中文候选。
- [ ] 重新开启不收回已输入文字，随后输入出现候选；方案记忆和候选开关互不覆盖。

## 第二阶段：全量验收

最小验收通过后，按《中英文符号核对报告》的 26 行逐项验证：浅色/深色、竖屏/横屏、普通/Shift/大写锁定，上滑与长按输入相同码点。确认长按左右滑选、默认符号、远移取消与上滑互斥。

## 支持边界

外部原生菜单独立更换方案不保证同步布局；请使用皮肤自己的方案面板。英文回中文使用配套 Lua 保存的最近中文方案，无记录时为 double_pinyin_flypy。若冷启动恢复错配、组合动作执行错误或英文候选异常，请记录入口、键盘类型、方案 ID、ASCII 状态和实际字符，此时不将版本标记为实机验收通过。
