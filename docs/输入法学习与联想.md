# 薄荷的个人学习与联想

## 原生造词与个人词频

三个中文方案已经启用用户词典。它们使用同一份 `rime_mint` 用户词典，学习结果可在小鹤双拼、全拼和小鹤混输之间共享。无需开启按键纠错来造词。

输入完整编码，在同一次预编辑中依次选择目标字词，最后整体上屏，可以学到完整新词。例如在隔离测试中输入 `kulimu`，分选「库」「莉」「姆」后整体提交。这里只是测试例子，不预置到你的个人词库。

分两次上屏「库莉」和「姆」后，下一次也可能出现「库莉姆」，但可能仍是临时组句；候选类型 `sentence` 与已学词 `user_phrase` 不同。整体选中提交后才算完整造词。选择现有候选也会更新个人词频；不人为把「那个」固定置顶，因为「哪个」同样是正常词。

已上屏后在宿主输入框里改字，不等同于上述造词。用户词典的近期退格回滚受引擎事件、事务和时间窗口限制，手机上的删除未必全部经过这条链路。

原生验证：运行 `python scripts/check_rime_learning.py`。需要 Windows 小狼毫 0.17.4、PyYAML 和 lupa；测试在新建的 `.tools/rime-learning-*` 目录部署，不复制个人数据库。测试字词及数据库不应导入手机。

元书实机检查：同一预编辑分段选词 → 整词上屏 → 重打编码；切换三个中文方案以及重启键盘后检查学习是否保留。Windows 引擎测试不能替代实机结果。
